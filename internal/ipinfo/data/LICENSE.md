DB-IP Lite data attribution

This directory includes the unmodified November 2026 DB-IP IP to ASN Lite and
IP to Country Lite databases, created by DB-IP / Eris Networks S.A.S.

Attribution: IP Geolocation by DB-IP — https://db-ip.com

DB-IP requires a visible link to https://db-ip.com on web pages that display or
use this data. The backend exposes this attribution in /network/ipdb. The frontend must
display the link with affected results. Trace-result integration and text
exports must retain the attribution when database-derived fields are added.

Data is approximate and has reduced coverage/accuracy compared with DB-IP's
commercial editions. IP geolocation is not proof of a router's physical location,
service tier, or transit path. No DB-IP City database is bundled; city data is an
optional separately downloaded DB-IP Lite dataset under the same license.

The files are gzip-compressed MMDB downloads without content modifications.
manifest.json records the release, source URLs, sizes, and SHA-256 of expanded
files for reproducibility. These are public datasets, not credentials.
