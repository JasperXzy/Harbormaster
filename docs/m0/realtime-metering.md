# 实时计量与额度保护

## 已确认的规则

- CDT 按流量对象只计出站；共享带宽包先合并同一计费对象所有成员的 RX、TX，再逐 UTC 小时取较大方向，最后相加。不能逐实例取大，也不能整段窗口只取一次大。
- 采集累计值以同一 counter epoch 的有效前后样本作差，使用单调时钟时长计算速率。缺测、未知归属与未安装 agent 不作为零流量。
- 累计样本跨小时或截止边界时无法还原精确分配。计量核心对每个相交小时计入完整区间字节，显式标为上界分配；不伪造均匀流量。小时中间的 dominant 增量也标为上界。
- 离线推算使用完整连续最近 10 分钟的双向峰值；历史不足、存在缺口或配置强制带宽模式时，使用公网配置带宽上限。它是 PRD 的推算策略，不能保证未来流量不会超过历史峰值。恢复收到累计数据后，以实际区间替换推算。
- 触发值为 `max(官方累计, 估算累计) + 当前计费速率 × 提前量`，达到阈值即触发；计算上溢返回错误。

`internal/metering` 只负责数值与覆盖计算。支持按时间顺序流式输入，常驻数据规模为成员数和小时数，避免长时间官方故障时加载整月原始采样。

## 用户已批准的边界

2026-11-18：有可信官方统计截止时间时按截止对齐；没有时可使用可配置延迟窗口，明确标为未核实、可能重复或漏计，只用于展示与演练。采集时间不是官方截止时间。

2026-11-18：服务自身身份未知时阻止自动停机；允许部署配置指定自身实例或明确声明不在纳管实例中，主机绑定不随数据库备份迁移。

2026-11-18：每实例默认 10 分钟最多 3 次真实自动电源动作，持久保存；演练不占真实动作次数。真实电源与释放开关继续关闭。

## 持久化与双路径（第二阶段）

迁移 046 扩展 CDT 观测的来源、单位质量、明确账期和截止字段；当前 ListCdtInternetTraffic 适配器仍只产生 inferred 值，没有补造可信水位。只有单位、账期、截止均受来源确认的内部观测才进入 aligned 路径。没有允许浏览器上传“官方水位”或把未知 CDT 归属强制设真的接口。

未核实窗口从“该官方观测抓取时间 − 延迟窗口”开始，到当前可共同覆盖的采样时刻；官方失败时继续使用同一基准及其原窗口起点，不能把失败抓取当成新基准。默认 3600 秒是本地假设，可通过 `GET/PUT /api/v1/traffic/estimation-settings` 调整为 60–604800 秒；不表示已验证阿里云的统计延迟。修改使用 revision，失效旧缓存。可指定实例强制使用公网带宽离线推算。

后台每 10 秒在一致 SQLite 事务中重算，GET 只读缓存。账号 revision、凭据版本、配置 revision 和基准观测 ID 隔离旧缓存；超过 30 秒的计算显示 stale。原严格对齐字段只在合格 aligned 结果下填充；未核实展示只读取 `QuotaStatus.estimation` 或 `Instance.traffic_estimation`（后者是所在账号＋区域的共享值）。

已知计费对象成员的完整发现结果存储稳定指纹和连续观测起点；首次发现之前、发现不完整、拓扑变更、间隔超过 15 分钟或已过期都不能声称拥有完整历史。连续观测不是权威的历史绑定时间，当前质量为 observed，真实自动执行资格保持 false。没有成员的对象、实例同时对应多个独立计费对象、缺少 agent 或时钟／计数异常都会留下明确原因与 null 完整总值。已计算部分保留便于诊断。

共同结束时刻选取在线 agent 的最新可用采样最小值；尚未采集到的几秒不虚构成零。离线超过 30 秒且实例仍 Running 时推算到这个共同结束时刻；全部离线时推算到当前计算时刻。原始区间流式读取，仅保留最后 10 分钟峰值需要的数据，回补后重新计算自然替换投影。

### 前端对接

新增字段和配置接口见 OpenAPI 顶部 2026-11-18 记录。Claude 需要按 `estimation.mode/status/reasons` 展示“未核实估算／演练”或缺少覆盖的原因；不能根据 agent online 判断已保护，不能把 `calculated_at` 或 `to_at` 说成官方截止。当前未改前端源文件或文案。官方累计仍显示单位及口径待核实。

## 保护规则与执行守卫（第三阶段）

迁移 047 保存规则、修订号、每周期的事件代数、判定历史、模拟用量、临时豁免、电源任务关联及真实自动动作台账。配置接口位于 `/api/v1/protection/`；只有面板会话可管理，写入仍须 CSRF。没有 API Key、agent 或任意命令入口。

规则明确指定账号与 CDT 国内／海外或单台轻量流量包、字节／整数百分比阈值、仅通知／停机通知、目标、ECS 停机模式、提前秒数和试运行。按量以外或付费类型未知时不允许节省停机。轻量当前也没有可靠官方截止，使用明确标记的未核实窗口，只能演练。

每 5 秒本地判断一次；触发值包含共同采样水位到当前时刻的速率补偿，再加配置的停机提前量，整数向上取整。未知完整估算不会被当成零；如果已知官方值本身已越线仍记录阈值事件，但不因此获得真实执行资格。没有有效数据时不清除原来的告警。

判定区分 would_stop、power_disabled、source_unqualified、自身未知／排除、豁免、已经停止、频控、忙碌和入队。演练、未核实来源和关闭电源的结果是已完成的本地记录，不生成稍后可重放的电源任务；要以新规则意图重新判断，需编辑规则或形成新的越线事件。临时豁免、忙碌和频控会在条件改变后重新检查。

模拟值只覆盖判定输入，不改写官方观测或采集账本，并且无条件强制演练。显式提供 24 小时内的到期时间，也可提前清除；到期按真实来源重新判断。轻量的模拟仍只针对本实例。通知写入现有持久化 outbox，保留固定占位文字，告警／恢复／执行结果不受静默限制；此工作不启用 Telegram 生产发送器。

真实路径复用既有电源 worker 的新鲜定点状态观察、一次发送标记和最终状态确认。**发送标记事务中**再次读取规则修订、账号／地域、最新官方基准、全部计量证据、模拟状态、自身绑定、豁免和每实例 10 分钟 3 次台账；不信任排队时的缓存。被拒绝或结果不明的已发送请求也占次数，不能通过重试绕过。自动队列尚未发送时不改期望状态，在实际发送标记处才设 quota_stopped；手动电源仍遵循已批准的入队即保存意图规则。

额度停机后手动开机，默认一小时豁免；也可用专门接口设置／清除 1–86400 秒豁免。新豁免重新安排相关规则的判定代数，到期会再次受到保护。规则编辑／删除取消尚未发送的旧自动任务，不撤回已发送动作。备份恢复取消旧任务／待发通知，不补发旧任务完成消息；清空估算缓存和拓扑连续性，并隔离真实自动发送 10 分钟，避免旧备份缺少最近动作台账而绕过频控。

自身绑定来自部署配置 `server_instance_id`（Harbormaster 内部实例 ID）或 `server_not_managed=true`，两者互斥；对应环境变量为 `HM_SERVER_INSTANCE_ID` 和 `HM_SERVER_NOT_MANAGED`。均未指定时，用固定 IMDSv2 读取并唯一匹配已纳管 ECS；读取失败、未匹配或歧义都保持未知。轻量必须显式绑定。配置在数据库之外，恢复数据库不会把旧机器身份迁移过来。规则若显式填写当前绑定的 `confirmed_self_instance_id` 才可包含自身；未知身份不能用该字段绕过。API 提供状态与逐实例标记供前端展示。

测试已覆盖：临界提前量、未核实与关闭开关、模拟到期及账本隔离、自身排除／确认、豁免到期、排队后规则／来源／豁免变化、跨重连频控、期望状态和去重。假云集成通过一次 stop 接受、最终停止状态确认、额度期望状态及两条紧急 outbox 记录：真实云调用 0。

PRD 建议补充：区分手动入队意图与自动发送时意图，明确关闭开关／未核实演练不留云任务，以及备份恢复的操作窗口隔离规则。这些都是避免旧意图或旧台账影响新部署的实现边界。

## 同截止对账（第四阶段）

迁移 048 将每次官方观测的比较结论和跨重启连续计数持久化。新观测必须有明确同一账期、字节单位和可信截止；用前一个可信基准加上**到新截止为止的实际区间**预测，再与新官方值比较，不能拿“现在的估算”对比“滞后的官方值”。

历史比较不使用离线投影，也不采用跨边界的上界分配；未知计费归属／成员、缺口、变化、非精确小时计量和缺少某区域的基准均明确不可比较。重复截止不推进计数，退后的水位不能降低最大已见水位。不可比较记录打断连续次数，保留已有事件而不假装恢复。新账号版本／账期不会重放已经处理的观测。

用户已确认以官方值为分母，严格超过 10% 才异常；0／0 正常，预测非零／官方零为异常，但相对比例返回 null，不输出无穷大。触发判断使用整数大数比较，展示比例的浮点四舍五入不会改变临界判断。

`cdt_estimation_deviation` 的触发默认连续 3 次不同截止的精确可比观测；恢复次数通过 alert-rule 的 `recovery_samples` 显式配置。2026-11-18 用户进一步确认连续 3 次正常后恢复，默认触发／恢复均设为 3；启用状态下不能遗漏恢复参数。独立测试明确传入 3，已验证三次异常触发、重复截止忽略、失败打断且保持事件、三次正常恢复和不重放。生产当前来源没有可信 cutoff，仍只会产生不可比较记录，不把单位假设包装成真实对账。

查询使用 `GET /api/v1/traffic/reconciliations`，支持账号、范围和整数 before 游标；`QuotaStatus.reconciliation` 返回当前账号版本／周期的最新结论。GET 只读本地记录。异常、恢复也使用固定占位文字进入紧急 outbox，不在本阶段启用外部消息发送。

实际针对性检查：`go test -race ./internal/store ./internal/api ./internal/metering ./internal/model -run 'TestReconciliation|TestDeviation|TestDualEstimate|TestQuotaThrough' -count=1` 通过（store 7.580s、api 3.300s、metering 1.328s）。另覆盖缺少某区域官方基准和单个账号上溢不阻塞其他账号；`go build ./... && go vet ./... && git diff --check` 退出 0。
