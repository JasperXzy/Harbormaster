# 实时计量与额度保护

## 已确认的规则

- CDT 按流量对象只计出站；共享带宽包先合并同一计费对象所有成员的 RX、TX，再逐 UTC 小时取较大方向，最后相加。不能逐实例取大，也不能整段窗口只取一次大。
- 采集累计值以同一 counter epoch 的有效前后样本作差，使用单调时钟时长计算速率。缺测、未知归属与未安装 agent 不作为零流量。
- 累计样本跨小时或截止边界时无法还原精确分配。计量核心对每个相交小时计入完整区间字节，显式标为上界分配；不伪造均匀流量。小时中间的 dominant 增量也标为上界。
- 离线推算使用完整连续最近 10 分钟的双向峰值；历史不足、存在缺口或配置强制带宽模式时，使用公网配置带宽上限。它是 PRD 的推算策略，不能保证未来流量不会超过历史峰值。恢复收到累计数据后，以实际区间替换推算。
- 触发值为 `max(官方累计, 估算累计) + 当前计费速率 × 提前量`，达到阈值即触发；计算上溢返回错误。

`internal/metering` 只负责数值与覆盖计算。支持按时间顺序流式输入，常驻数据规模为成员数和小时数，避免长时间官方故障时加载整月原始采样。

## 用户已批准的边界

2026-11-18：有可信官方统计截止时间时按截止对齐；没有时可使用可配置延迟窗口，明确标为未核实、可能重复或漏计，只用于展示与演练。采集时间不是官方截止时间。

2026-11-18：服务自身身份未知时阻止自动停机；允许部署配置指定自身实例或明确声明不在纳管实例中，主机绑定不随数据库备份迁移。

2026-11-18：每实例默认 10 分钟最多 3 次真实自动电源动作，持久保存；演练不占真实动作次数。真实电源与释放开关继续关闭。

## 分阶段验证

计量核心：`go test -race ./internal/metering -count=1`。覆盖共享成员方向相反、跨小时、区间边界、未知覆盖、离线回补替换、单调时间、整月流式输入及整数溢出。后续阶段另行记录持久化和接口验证。
