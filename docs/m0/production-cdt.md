# CDT 累计记录与流量页面

2026-11-12，接续账号与只读资源发现阶段。

## 用户确认与数据边界

用户明确允许将 `ListCdtInternetTraffic.Traffic` 暂按字节展示，同时标注“单位及计费口径待核实”。依据是实际响应第一阶梯上限为 `10 × 1024^4`；这只是推断证据，不是接口返回的单位声明。此决定独立于本地额度的 1024³ 换算约定。

来源仍未提供账期和统计截止时间。本阶段不会把 `fetched_at` 作为截止时间，不计算“官方 + 截止后增量”，不推算每日真实用量，不启用依赖精确对齐的保护。PRD 原文未修改；建议保留此前提出的来源质量与 cutoff 可空修订。

## 实现

- 新增 `cdt_observation`，保存每次实际读取的时间、国内/海外累计值、允许的地域/线路字段及固定错误码。记录关联任务和尝试次数，可幂等落库。所有写入继续核对任务租约、账号租约和配置版本。
- 只有来源明确返回零时保存零；没有返回某个范围、响应异常、重复地域/线路、非整数、过大值和未确认线路均不转换成零。
- 暂只合并已识别的 `bgp` 线路。其他线路返回待验证状态，避免把不同免费额度资格的流量混算。
- CDT 独立调度，默认 300 秒；`cdt_poll_interval_seconds` / `HM_CDT_POLL_INTERVAL_SECONDS` 可配置 60–86400 秒。读取失败按现有任务机制处理，保留历史，停用账号不再调度。
- 手动刷新按契约同时读取资源与 CDT；自动资源扫描和 CDT 轮询分别遵循各自周期。最近的实际抓取会抑制一次重复定时抓取。
- 凭据轮换递增 `credential_version`：旧记录保留在历史中，但不会作为新凭据的当前累计值。
- `/traffic/quotas` 区分 `official_bytes`、`fetched_at`、`official_as_of` 和 `official_quality`。当前真实来源质量为 inferred，cutoff 与估算/有效值/预测保持 null。失败时保留同一参考周期内的旧可用值，并显示 unavailable。
- 参考周期按面板业务时区的自然月生成，仅用于本地额度展示和避免跨月复用旧记录，不表示云侧确认了账期。来源跨月延迟或补账仍需进一步核实。
- `/traffic/observations` 提供带游标的累计抓取历史；前端可切换曲线与表格，明确它不是每日真实用量。
- `/traffic/daily` 在没有可靠日来源时返回日期与 null 数值、`daily_source_unverified`。不会将两次累计抓取的差值归到某一天。共享带宽小时采样尚未到位时返回空记录，不画假零曲线。
- SSE 在相关任务结束后更新额度快照；顶栏在没有有效实时估算时显示“实时估算待确认”，不会把官方抓取时间显示成实时计量时间。

## 验证

真实只读扫描在已有隔离验证库完成，未使用新的账号、未修改云资源。读取结果：

| 账号 | 内地累计 | 海外累计 | 质量 |
|---|---:|---:|---|
| jasperxzy | 1745430210 | 43643409480 | 暂按字节，inferred；cutoff_unknown |
| winnemjw | 未返回，保持 null | 明确返回 0 | 海外为 inferred；不把内地缺失当零 |

上述数值是当次读取的原始整数按字节暂解释，不是持续更新的状态，也不是已核实账单。所有行的统计截止时间和实时估算仍为空。

测试覆盖直接/嵌套响应、重复地域、无数据与零、异常线路、溢出、失败保留旧值、跨月处理、凭据轮换保留历史但不复用当前值、独立调度、停用、GET 不查云、每日数值不伪造。桌面与 390×844 手机页面已观察验证，页面没有横向溢出或 NaN/Infinity，抓取曲线与表格可切换。
