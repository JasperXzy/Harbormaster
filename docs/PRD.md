## 1. 背景

名下有多个阿里云账号，持有 ECS 和轻量应用服务器，计费方式三种：

| 计费方式 | 适用资源 | 额度 |
|---|---|---|
| **CDT 公网流量** | 按流量计费的 ECS、EIP 等 | **按账号**：每月中国内地 20GB + 非中国内地 200GB 免费，超出阶梯计价 |
| **轻量服务器流量包** | 轻量应用服务器 | **按实例**：套餐自带月流量 |
| 固定带宽 | 按固定带宽计费的 ECS | 不按流量收费，不参与 CDT |

参考项目都只覆盖 ECS 与 CDT；运维中还反复遇到它们没有覆盖的问题：轻量服务器的流量包与防火墙、安全组端口放行、实例规格带宽低于购买的公网带宽、突发实例性能衰减等（其中防火墙与安全组管理已延后，见第 14 节）。

## 2. 目标与非目标

### 2.1 目标
- **G1 统一视图**：全部账号的实例、CDT、轻量流量包、费用一处可见。
- **G2 额度保护**：阈值告警、月底预测、自动停机、定时开关机、保活、月初开机。
- **G3 资源操作**：开机 / 关机 / 重启、更换 EIP、创建 / 释放实例，都在面板或 Telegram 完成。
- **G4 主动发现问题**：规格带宽不足、CPU 积分耗尽、系统维护事件、闲置计费资源、即将到期。
- **G5 可靠与安全**：任务队列防重复执行、补偿执行、加密存储、最小权限、Passkey、加密备份。
- **G6 延迟监控**：像探针一样查看各实例之间、到常用目标的延迟、丢包与线路（只做 ICMP / TCP 层）。

### 2.2 非目标
- 不监控非阿里云的机器：账号只支持阿里云，实例只支持 ECS 与轻量应用服务器；hm-agent 只能安装在已纳管的阿里云实例上。
- 不做代理节点、订阅、证书等应用层检查，不做应用层的全链路探测（延迟监控只到 ICMP / TCP 层）。
- hm-agent 不采集应用数据，不执行任意命令，只做公网流量上报、延迟测速与线路追踪（见 F12）。
- 不使用云助手，不申请云助手权限。
- 不提供任何改变或伪装流量特征的功能。

## 3. 使用场景

| 编号 | 场景 | 期望 |
|---|---|---|
| S1 | 打开面板 | 看到各账号 CDT 用量与预测、额度池总余量、轻量流量包、所有实例状态、待处理问题 |
| S2 | 新增阿里云账号 | 首次向导或设置页添加；自动测试权限（通过 / 缺少权限 / 未验证 / 检查失败），自动发现实例 |
| S3 | 用量越过阈值 | Telegram 通知；按规则"仅通知"或"停机并通知" |
| S4 | 每天固定时段 | 定时开关机；错过时间点（如服务重启）在补偿窗口内补执行 |
| S5 | 抢占式实例被回收停机 | 保活自动开机；额度保护优先于保活 |
| S6 | IP 被墙或需要换 IP | 面板或 Telegram 一键更换 EIP 并通知（自动同步 DNS 延后，见第 14 节） |
| S7 | 共享带宽 / 按主流量的机器 | 按入、出方向较大值实时计量，与 CDT 官方数据对账 |
| S8 | 买了大带宽但跑不满 | 面板提示"实例规格带宽低于公网带宽" |
| S9 | 手机上看状态 | 桌面小组件显示用量；Telegram 发 `/status` |
| S10 | 迁移或灾备 | 下载加密备份，在新机器恢复 |
| S11 | 给实例安装 agent | 面板生成一行安装命令；agent 自动绑定到对应实例，几十秒内面板出现实时流量 |
| S12 | 在阿里云控制台手动关机 | 保活不会把它重新开机（期望状态为"停止"的实例不保活，见 F6.9） |
| S13 | 上线前演练额度保护 | 用规则试运行或模拟用量走通"越线 → 停机 → 通知"，不消耗真实额度 |

## 6. 流量计量（v0.4 新增）

### 6.1 计费对象与计量规则

流量不是按"机器"计费，而是按**计费对象**计费。同一台机器的公网流量，计费规则取决于它的公网 IP 挂在哪里：

| 计费对象 | 判断依据 | 计量规则 | 结算 | 是否计入 CDT 额度 |
|---|---|---|---|---|
| ECS 公网 IP，按流量 | 实例 `InternetChargeType = PayByTraffic` | **只算出方向** | CDT | 是 |
| EIP，按流量（未加入共享带宽） | EIP 计费方式为按流量 | **只算出方向** | CDT | 是 |
| **共享带宽，按主流量**（`PayByDominantTraffic`） | EIP 加入了共享带宽 | **每个计费周期取入、出方向流量的较大值** | 2024-12-17 之后新建的由 **CDT** 结算；之前建的按原共享带宽规则（可升级到 CDT） | 新建的：是 |
| 共享带宽，按带宽 / 增强型 95 | 共享带宽计费方式 | 不按流量计费；按带宽或 95 峰值计费（95 峰值是否取出入较大值，在 M0 验证） | 共享带宽账单 | 否 |
| 轻量服务器流量包 | 实例类型为轻量，且套餐带流量包 | 按套餐规则（统计方向以接口返回为准，在 M0 验证）；**部分套餐不含流量包**（如 sha-pro：`ListInstancesTrafficPackages` 返回为空），此时不做流量计量 | 轻量服务器 | 否（按实例） |
| ECS 固定带宽 | `PayByBandwidth` | 不按流量计费 | 包月 | 否 |

> 实例：sin-pro（jasperxzy 账号，新加坡）本身没有公网带宽，公网走 EIP 8.219.235.129；该 EIP 加入共享带宽 sg-share（2000Mbps，**按主流量**，2026-11-11 创建），因此其流量**按每周期 max(入, 出) 计量、由 CDT 结算**。作为转发机器，它的入、出方向流量接近，主流量约等于其中任一方向。
>
> hkg-pro（jasperxzy 账号，香港）按流量计费、计入 CDT；公网 IP 形式（实例公网 IP 或 EIP）在 M0 核对。

### 6.2 官方数据 + 实时估算

| 来源 | 内容 | 延迟 | 用途 |
|---|---|---|---|
| **CDT 官方** | 账号级当月公网流量（国内 / 海外） | 约 1 小时 | 计费依据；对账基准 |
| **hm-agent 实时** | 每台实例的公网入方向 / 出方向累计字节（只统计公网，排除内网网段；含转发流量），每 10 秒上报 | 约 10 秒 | 实时估算、额度保护、按资源归因 |
| 云监控（辅助） | EIP、共享带宽的公网流量指标；CPU、CPU 积分 | 约 1–2 分钟 | 对账参考、未装 agent 的对象的流量展示；**不作为额度保护依据** |

**实时估算 = 最近一次 CDT 官方值 + 该时间点之后各计费对象按 6.1 规则计算的增量**：
- 按流量的 ECS / EIP：增量 = 出方向字节；
- 按主流量的共享带宽：按计费周期（按小时聚合，周期长度在 M0 验证）分别累计全部成员实例的入、出方向，取较大值；
- 不计入 CDT 的对象（固定带宽、按带宽 / 95 的共享带宽、轻量）不参与 CDT 估算；
- 国内 / 海外归属：按实例所在地域，中国内地地域的增量计入国内额度，其余计入海外额度；
- 对齐：增量从 CDT 官方数据的截止时刻起算（官方数据的时间粒度与截止时刻在 M0 验证）；agent 上报的是累计计数，服务端按时间点求差，丢失个别上报不丢数据；
- 计入 CDT 的实例必须安装 agent 才能启用额度保护规则；未安装的在面板标为"未受实时保护"，其流量只能通过官方数据（延迟约 1 小时）体现。

**判断与对账**：
- 额度告警与额度保护使用 **max(官方值, 实时估算)**，避免因官方延迟而晚触发；
- 每次新的 CDT 官方数据到达时，用它替换估算的基准，并记录"估算 − 官方"的偏差；连续偏差超过 10% 时告警，提示可能有未纳入监控的计费对象（未装 agent 的实例、负载均衡、NAT 网关等）；
- **agent 掉线按最坏情况推算**：某实例的 agent 掉线（默认连续 30 秒无上报）且实例仍在运行时，掉线期间的增量按"掉线前 10 分钟内的峰值速率 × 掉线时长"累计（窗口长度可配；掉线前的数据不足 10 分钟时改用带宽上限；也可按实例改为始终用带宽上限）；估算因此越过保护阈值时照常停机。agent 恢复后用真实累计差值替换推算值；
- CDT 官方接口取不到数据时，沿用最近一次官方值 + agent 增量继续判断，并告警；
- 面板同时显示"官方（截至 hh:mm）"与"实时估算"，并标出两者差值。

### 6.3 按资源归因
CDT 只给出账号合计；按资源的用量来自 hm-agent 上报的数据，用于回答"这个账号的流量主要是哪台机器、哪个共享带宽用掉的"。

## 9. 非功能需求

| 类别 | 要求 |
|---|---|
| 资源占用 | hm-server 常驻内存 ≤ 100MB；hm-agent 常驻内存 ≤ 20MB、CPU 占用可忽略 |

## 10. 内置告警规则

| 规则 | 默认阈值 |
|---|---|
| CDT 海外 / 国内用量 | 80% / 90% / 95% |
| CDT 预计月底超额 | 预测 > 额度 |
| 轻量流量包用量 / 预计用尽 | 80% / 90% / 95%；早于重置日 |
| 额度保护已执行 / 主备切换已执行 | 每次 |
| 实例意外停止 / 保活已开机 | 每次 |
| 实例公网 IP 变化 | 每次 |
| 规格带宽不足 | 发现时 |
| CPU 积分低 | < 20% |
| 系统事件 | 发现时 |
| 即将到期 | ≤ 7 天 |
| 余额不足 | < 设定金额 |
| 闲置计费资源 | 发现时 |
| 账号接口调用失败 | 连续 3 次 |
| agent 掉线（开始按最坏情况推算） | 连续 30 秒无上报 |
| CDT 官方数据不可用 | 连续 3 次拉取失败 |
| 实例在面板之外被关机（等待确认期望状态） | 发现时 |
| 规则试运行命中 | 每次（标注"试运行，未执行"） |
| 官方与实时估算偏差 | 连续 > 10% |
| 延迟过高 / 丢包 / 不可达 | 延迟 > 阈值持续 10 分钟；丢包 > 5%；连续 3 次不可达 |
| 线路变化 | 定时快照的 ASN 序列与上次不同 |

> 通用规则：状态类告警在恢复时发送恢复通知（F8.8）；"发现时"类规则同一问题只通知一次（F8.9）；静默时段内非紧急告警不推送（F8.10）。

## 11. 数据模型（核心实体）

`account`、`instance`（kind = ecs / swas；含期望状态与豁免到期时间）、`agent`（绑定实例、token 哈希、版本、最后上报时间）、`eip`、`bandwidth_package`（共享带宽）、`billing_subject`（计费对象与规则）、`traffic_sample`（agent 上报的公网入 / 出累计计数）、`traffic_estimate`（含最坏情况推算标记）、`usage_override`（模拟用量）、`probe_source`、`probe_target`、`probe_task`、`probe_result`、`route_trace`（逐跳结果、ASN 序列、线路类型）、`cdt_snapshot`、`swas_package_snapshot`、`metric_sample`、`guard_rule`、`schedule`、`keepalive`、`failover_rule`（自动化规则均含试运行标记）、`job`（持久化任务，含租约与事件键）、`action_log`、`alert_rule`、`alert_state`（去重与恢复）、`notification`（outbox）、`api_key`（scope、哈希）、`passkey`、`audit_log`、`setting`。
