# Harbormaster 设计规范

面板的视觉与文案规则。取值沿用仓库外的静态 demo（`../demo/index.html`），实现在 `web/src/styles/`。
写新页面前先看这里；要新增颜色、字号或组件，先改本文件再改代码。

## 1. 原则

- **先说结论，再给数字。** 读的人不一定懂云计费。每块内容先用一句话或一个状态徽标说明"有没有问题"，数字放在后面。
- **数字必须带时间。** 来自阿里云或采集程序的数据都显示"截至 hh:mm"；超过时限没更新就明确标出"已过期"，不让旧数字看起来像新的。
- **状态不只靠颜色。** 每个级别同时有不同的形状（圆勾、三角、菱形、圆叉、空心圆）和文字。
- **不引入界面组件库。** 所有组件自己写，样式只用本文件列出的变量。

## 2. 颜色

变量定义在 `web/src/styles/tokens.css`。深色模式重新定义同一组变量，组件里不写死颜色。

| 用途 | 变量 | 浅色 | 深色 |
|---|---|---|---|
| 页面背景 | `--page` | `#f9f9f7` | `#0d0d0d` |
| 卡片、侧栏、顶栏 | `--surface` | `#fcfcfb` | `#1a1a19` |
| 次级底色（悬停、徽标底、输入框组） | `--surface-2` | `#f3f3f0` | `#232321` |
| 正文 | `--text` | `#0b0b0b` | `#f0efec` |
| 次要文字 | `--text-2` | `#52514e` | `#c3c2b7` |
| 辅助说明、表头 | `--muted` | `#898781` | `#898781` |
| 描边 | `--border` | 黑 10% | 白 10% |
| 强调（主按钮、链接、选中） | `--accent` | `#2a78d6` | `#3987e5` |

**状态色**（两种模式相同）

| 级别 | 变量 | 色值 | 图标形状 | 什么时候用 |
|---|---|---|---|---|
| 正常 | `--good` | `#0ca30c` | 圆 + 勾 | 运行中、在线、通过、不会超额 |
| 警告 | `--warning` | `#fab219` | 三角 + 叹号 | 需要留意但不紧急：预计会超额、数据过期、未设置通知 |
| 较重 | `--serious` | `#ec835a` | 菱形 + 叹号 | 应该尽快处理：用量过 80% / 90%、未受实时保护、缺少权限 |
| 严重 | `--critical` | `#d03b3b` | 圆 + 叉 | 正在出问题：用量过 95% 或已超额、采集程序掉线、账号连接失败、发送失败 |
| 中性 | `--muted` | `#898781` | 空心圆 | 没有好坏之分：已停止、未安装、未验证 |

状态色只用在图标和少量文字上，不做大面积底色。横幅用很淡的底（`--tint-warning`、`--tint-critical`）。

**图表色**

| 变量 | 浅色 | 深色 | 固定含义 |
|---|---|---|---|
| `--series-1` | `#2a78d6` | `#3987e5` | 非中国内地（海外）用量；折线图里的"发出" |
| `--series-2` | `#eb6834` | `#d95926` | 中国内地（国内）用量 |
| `--series-3` | `#1baf7a` | `#199e70` | 折线图里的"收到" |
| `--realtime` | `#86b6ef` | `#184f95` | 实时增量（官方还没算进去的部分） |
| `--forecast` | `#86b6ef` | `#1c5cab` | 预测（斜纹或虚线） |
| `--grid` / `--axis` | `#e1e0d9` / `#c3c2b7` | `#2c2c2a` / `#383835` | 网格线 / 基线 |

一种颜色在整个面板里只表示一个意思：海外永远是蓝，国内永远是橙。

## 3. 字号与字体

字体：系统默认无衬线（`--font`）；实例 ID、IP、命令用等宽（`--font-mono`）。数字列统一 `font-variant-numeric: tabular-nums`。

| 变量 | 大小 | 用在哪 |
|---|---|---|
| `--fs-stat` | 28px（手机 22px） | 总览的四个大数字 |
| `--fs-xl` | 18px | 页面标题 |
| `--fs-lg` | 15px | 卡片标题 |
| `--fs-base` | 14px | 正文 |
| `--fs-md` | 13px | 表格、表单、按钮、说明段落 |
| `--fs-sm` | 12px | 辅助说明、徽标、图例、时间 |
| `--fs-xs` | 11px | 标签、图表刻度 |

字重只用三档：400 正文、600 强调、650 标题与大数字。手机上的输入框固定 16px，避免 iOS 聚焦时放大页面。

## 4. 间距、圆角、布局

- 间距取 4 的倍数：`--sp-1`…`--sp-7` = 4 / 8 / 12 / 16 / 20 / 24 / 28px。卡片内边距 18×20（手机 14），卡片之间 16，页面各段之间 20。
- 圆角：标签 6（`--r-sm`）、按钮与输入框 8（`--r-md`）、卡片 12（`--r-lg`）、弹窗 14（`--r-xl`）、徽标与开关为全圆角。
- 阴影只有浅色模式的卡片有极淡的一层；深色模式靠描边区分层次。

**断点**

| 宽度 | 布局 |
|---|---|
| > 1180px | 左侧 216px 侧栏；四栏 / 三栏 / 两栏网格 |
| 781–1180px | 侧栏保留；四栏变两栏，两栏变单栏 |
| ≤ 780px | 侧栏变成底部标签栏（图标 + 文字）；内容单栏；表格换成卡片列表；弹窗从底部升起 |

手机上不允许页面横向滚动。确实放不下的宽表格只在卡片内部横向滚动；关键信息（额度对比、实例列表）在手机上改用额度条和卡片，不依赖横向滚动。

## 5. 组件

实现都在 `web/src/components/`。

| 组件 | 文件 | 用法 |
|---|---|---|
| 外壳 `Shell` | `Shell.tsx` | 侧栏 / 底部标签栏 + 顶栏。顶栏固定显示数据新鲜度、刷新、主题切换 |
| 卡片 `Card` | `ui.tsx` | 标题 + 一句副标题 + 右侧操作。一张卡片只讲一件事 |
| 状态徽标 `Badge` | `ui.tsx` | 图标 + 短语（"运行中""未受实时保护"）。短语写结论，不写枚举值 |
| 横幅 `Banner` | `ui.tsx` | 页面顶部需要用户处理的问题。一句加粗的结论 + 一句解释 + 一个去处理的按钮 |
| 新鲜度 `Fresh` | `ui.tsx` | "截至 17:42"；过期后自动变成"××已过期 · 停在 17:42" |
| 额度条 `QuotaMeter` | `QuotaMeter.tsx` | 实色 = 官方已用；浅色 = 实时增量；竖纹 = 掉线期间的推算；斜纹 = 预测到月底；竖线 = 免费额度 |
| 每日柱图 `DailyBars` | `charts/DailyBars.tsx` | 两个系列堆叠，较大的贴着基线；今天的柱子略淡（含未出账的实时增量） |
| 折线图 `LineChart` | `charts/LineChart.tsx` | 多条线、十字准线、线尾标签、参考线（免费额度）、标记点（预计超额日）、虚线（预测） |
| 开关 `Switch`、分段切换 `SegToggle` | `ui.tsx` | 开关用于立即生效的启用 / 停用；分段切换用于"图表 / 表格""海外 / 国内" |
| 弹窗 `Modal`、确认 `Confirm` | `ui.tsx` | 确认弹窗写清后果；不可恢复的操作（删除账号）要求输入名称 |
| 轻提示 `useToast` | `ui.tsx` | 操作结果的一句话反馈；出错的提示停留更久、用严重色 |
| 状态占位 `Skeleton` / `EmptyState` / `ErrorState` / `Async` | `ui.tsx` | 见第 6 节 |
| 复制按钮 `CopyButton`、命令框 `.codebox` | `ui.tsx` | 安装命令的展示与复制 |

图表规则：按容器实际像素宽度绘制（手机上文字不缩小）；每张图都有"图表 / 表格"切换或等价的文字说明；鼠标与触摸都能看到具体数值；图表有 `aria-label`。

按钮：一个区域最多一个主按钮（蓝底）；危险操作用红字按钮并且必须经过确认弹窗；处理中的按钮禁用并显示转圈。

## 6. 状态

每块数据都要考虑下面这些状态，不能只画"有数据"的样子。模拟模式左下角的"模拟场景"可以逐个切换查看。

| 状态 | 怎么表现 | 文案要点 |
|---|---|---|
| 加载中 | 灰色骨架条（`Skeleton`），保持卡片外形，不用整页转圈 | 不需要文字 |
| 空数据 | `EmptyState`：图标 + 一句"还没有××" + 为什么是空的 + 下一步按钮 | 告诉用户接下来做什么，例如"去添加账号" |
| 出错 | `ErrorState`：一句人话原因 + "再试一次" | 文案按错误码查表（`web/src/api/labels.ts`），不直接显示后端的英文 message |
| 后台刷新失败 | 保留上一次的数据，不清空；靠"数据过期"提示 | — |
| 数据过期 | `Fresh` 变成琥珀色："官方数据已过期 · 停在 17:41" | 写清是哪种数据、停在什么时候 |
| 实时连接断开 | 顶栏出现"实时连接已断开"；恢复后自动重新取数 | — |
| 采集程序掉线 | 实例显示严重级"按最坏情况推算"；总览顶部红色横幅；额度条出现竖纹段并注明其中多少是推算的 | 说明数字会偏大、为什么、去哪里排查 |
| 未受实时保护 | 实例显示较重级状态；总览顶部黄色横幅 | 核对采集程序和计量依据。缺少官方截止时间时，即使采集在线也不能确认实时保护 |
| 用量待确认（官方数据取不到，或没有说明统计到几点） | 额度条换成斜纹底，只显示能确认的官方数字；余量、比例、预测显示“待确认”或不显示；全空的图表用空状态占位 | 缺失的数不当作 0，读取时间不当作统计时间。**解释在一张卡片里只写一次**（`QuotaUnknownNote`），不在每条额度条下重复 |
| 已在采集但暂时算不出 | 实例显示警告级“暂无法估算”，不和没装采集程序的机器一起标“未受实时保护”（`protectionOf`） | 说明采集程序在正常上报，问题出在官方数据 |
| 账号连接失败 | 账号卡片严重徽标；总览红色横幅；设置页显示原因与连续失败次数 | 说明数据停在什么时候 |
| 试运行、模拟用量（M2） | 预留：整块内容加明显的条纹边框与"试运行 / 模拟"标签 | M2 设计时补充 |

过期时限（待后端确认，见契约 B19）：实时数据 60 秒、CDT 官方数据 2 小时、资源信息 30 分钟。

## 7. 文案

- 全部中文，面向非专业读者。能用日常说法就不用术语和缩写：

| 不这样写 | 这样写 |
|---|---|
| agent / hm-agent | 采集程序（第一次出现时可以括注 hm-agent） |
| CDT 额度 | 免费额度 / 免费流量 |
| 口径、对齐、计量依据、归属、数据来源 | 直接说事情本身：“没说明统计到几点”“没法加在一起”“是否计入免费额度” |
| 抓取 | 读取 |
| 入方向 / 出方向 | 收到 / 发出 |
| 计费对象 | 公网出口；"流量是按什么计费的" |
| PayByTraffic、max(入, 出) | 按流量；每小时取收、发中较大的一方 |
| token 已撤销 | 凭证已撤销 |
| SWAS、ECS | 轻量服务器、云服务器（表格里空间紧张时可用"轻量""ECS"标签） |

- 保留不翻译的专有名词：Telegram、AccessKey、Harbormaster，以及用户要照着输入的命令。
- 按钮写动作（"添加账号""再试一次"），不写"确定"。
- 出错信息 = 发生了什么 + 可以怎么办。不出现错误码以外的技术细节。
- 时间：今天只写"17:42"，其他日期写"11-10 22:05"；持续时间写"4 分 35 秒""10 分钟"。时区在设置里选，默认 Asia/Shanghai。
- 流量统一用 GB、保留 1 位小数，方便和额度比较；速度用 Mbps。
- 引号用中文引号“ ”。

## 8. 无障碍

- 所有可点的东西都能用键盘操作，焦点有 2px 强调色外框。
- 图标按钮有 `aria-label`；开关用 `role="switch"`；弹窗用 `role="dialog"`，Esc 关闭，关闭后焦点回到原处。
- 颜色之外必有文字或形状。正文（`--text`、`--text-2`）与底色的对比度不低于 4.5:1；`--muted` 沿用 demo 的取值，对比度较低（约 3.6:1），只用于辅助说明，不要用它写必须读到的内容。
- 尊重"减少动态效果"的系统设置（骨架、转圈、提示的动画会关闭）。
