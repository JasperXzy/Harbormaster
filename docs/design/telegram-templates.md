# Telegram 通知文案模板（M1）

面板“通知记录”里显示的标题和正文，与发到 Telegram 的是同一段文字，由后端按本文件的模板渲染（契约 B13）。
文字由前端定稿；发送、去重、重试由后端实现。

## 规则

- 第一行是标题：一句话说清发生了什么，带上账号或实例的名字。标题前的符号表示级别。
- 正文最多两行：第一行给关键数字，第二行说现在的处理方式或建议做什么。不写技术术语。
- 时间用设置里的时区，今天只写 `17:42`，其他日期写 `11-10 22:05`。
- 流量用 GB，保留 1 位小数；百分比不带小数。
- 数值缺失时整句省略，不写“待确认”或 0。
- 不放链接、不放按钮（远程控制在 M2）。

| 级别 | 符号 | 用在 |
|---|---|---|
| 严重 | 🔴 | 用量过 95% 或已超额、采集程序掉线 |
| 较重 | 🟠 | 用量过 80% / 90%、账号连接失败 |
| 警告 | 🟡 | 预计会超额、官方数据取不到 |
| 恢复 | 🟢 | 问题消失 |
| 测试 | ⚪ | 测试消息 |

## 变量

| 变量 | 含义 | 示例 |
|---|---|---|
| `{account}` | 账号名称 | jasperxzy |
| `{instance}` | 实例名称 | hkg-pro |
| `{scope}` | 海外 / 国内 | 海外 |
| `{threshold}` | 越过的档位（百分比） | 80 |
| `{used}` / `{quota}` | 判断用的用量 / 免费额度 | 168.4 GB / 200 GB |
| `{official}` / `{official_at}` | 官方数值 / 官方截止时间 | 164.8 GB / 16:00 |
| `{daily_avg}` | 近 7 天日均 | 15.1 GB |
| `{exceeds_on}` | 预计超出的日期 | 11-13 |
| `{rate}` | 推算用的速度 | 182 Mbps |
| `{offline_for}` | 掉线了多久 | 48 秒 |
| `{failures}` | 连续失败次数 | 3 |
| `{reason}` | 失败原因（按错误码取 `web/src/api/labels.ts` 里的说法） | AccessKey 不存在或已被禁用 |
| `{since}` | 数据停在什么时候 | 14:05 |

## 模板

### 免费额度用量（`cdt_usage`）

同一档位每个计费周期只发一次。档位 ≥ 95 用 🔴，其余用 🟠。

```
🟠 {account} 的{scope}免费额度已用超过 {threshold}%
已用 {used} / {quota}（官方截至 {official_at} 为 {official}）。
```

超出免费额度时（用量 ≥ 100%）：

```
🔴 {account} 的{scope}免费额度已经用完
已用 {used} / {quota}。超出的部分会开始计费。
```

没有恢复通知（下个计费周期自动重新开始）。

### 预计月底超额（`cdt_forecast_exceed`）

```
🟡 {account} 的{scope}额度预计 {exceeds_on} 用完
最近 7 天平均每天 {daily_avg}，现在已用 {used} / {quota}。
```

恢复（预测回到额度以内）：

```
🟢 {account} 的{scope}额度预计月底前够用了
```

### 采集程序掉线（`agent_offline`）

```
🔴 {instance} 的采集程序掉线了
已经 30 秒没有收到上报。掉线期间按它之前的最高速度（{rate}）估算用量，数字会偏大。
请登录这台机器，检查 hm-agent 是否在运行。
```

恢复：

```
🟢 {instance} 的采集程序恢复上报
掉线 {offline_for}，已用真实数值替换估算值。
```

### 账号连接失败（`account_api_failure`）

```
🟠 账号 {account} 连不上阿里云
连续 {failures} 次失败：{reason}。它的数据停在 {since}。
```

恢复：

```
🟢 账号 {account} 恢复连接
```

### 官方数据取不到（`cdt_official_unavailable`）

```
🟡 取不到 {account} 的官方流量数据
连续 {failures} 次读取失败，正用上一次的数值继续估算。
```

恢复：

```
🟢 {account} 的官方流量数据恢复读取
```

### 测试消息

```
⚪ 测试消息
如果你在 Telegram 里看到这条消息，说明通知已经配置好了。
```
